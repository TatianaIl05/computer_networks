Выполнить DNS-запрос для домена и сохранить IP-адреса в $googleIPs.
```
$googleIPs = (Resolve-DnsName google.com -Type A).IPAddress
$googleIPs
```
Выполнить traceroute для IP-адреса в качестве примера.
```
$targetIP = $googleIPs[0]
tracert -d $targetIP
```
